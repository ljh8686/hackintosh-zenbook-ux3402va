## 提示词正文

你是 macOS Swift/SwiftUI 开发者，在当前工作区（`/Applications/双系统/ASUS控制台-开发资料/`）继续开发原生 App「ASUS 控制台」。

### 机器（黑苹果环境）
- ASUS Zenbook UX3402VA / i9-13900H / Intel Iris Xe `8086:A7A0` / macOS 26.7.3(25G342) / OpenCore 双系统。
- **核显已硬件加速**（NootedGreen，VRAM 1536MB / Metal 2，已验证）。集显修复全套资料见 GitHub 仓库 `ljh8686/hackintosh-zenbook-ux3402va` 的 `修复成果-20261128/` 目录与 Release `nootedgreen-a7a0-20261128`。
- 没有官方 Armoury Crate。硬件控制走 **MHelper**：内核驱动 `org.franciumos.mhelper.driver 0.3.1`，外部方法 `AsusWMIControl`：`sGetInfo / sSetThermal / sSetKbd / sSetCharge`（用 IOKit IOConnectCallMethod 调用）。
- 音频：ALC294 + SimpleHDA + AppleALC 正常（耳机可用）；内置 CS35L41 功放为实验性、需冷启动，不稳定——**与本 App 无关，别动音频**。
- 触控板未通、蓝牙未解、睡眠不建议——都**与本 App 无关，别碰**。

### 目标
维护并增强「ASUS 控制台」App：日常可调 屏幕亮度/护眼、性能模式(风扇)、键盘背光、充电上限，显示系统状态，菜单栏常驻。

### 现状
- `/Applications/ASUS控制台.app` **当前缺失**（旧版被删），需重新编译安装。
- 源码在本目录：`main.swift`（约 48K，最新版）、`icon.swift`、`构建.sh`、`AppIcon.icns`。
- 参考：`技术数据.md`（WMI 外部方法/数值详解）、`交接-提示词.md`（旧交接）。
- **本机没有 swiftc / Xcode 命令行工具**：先让用户执行 `xcode-select --install`（会弹安装框，点安装+输密码），再 `bash 构建.sh` 编译打包（`swiftc -O -parse-as-library main.swift -o ...` + 打包 .app + `codesign --force --deep --sign -`）。
- 安装到 `/Applications/ASUS控制台.app`，bundle id `com.local.asusconsole`，`LSUIElement=true`（菜单栏常驻、无 Dock）。

### 已有功能（不要弄坏）
- 亮度：全屏覆盖层软件调光（暗罩+暖罩），白天/柔和/夜间护眼三档；快捷键 ⌃⌥↑/↓。
- 性能模式：静音/均衡/性能三键（WMI `sSetThermal` 0/1/2）；⌃⌥←/→。
- 键盘背光 0..3（`sSetKbd`）；充电上限 100/80/60（`sSetCharge`）。
- 系统状态：CPU/内存/电池/当前模式，2 秒刷新。
- 一键打开 MHelper。

### 可增强（按价值排序，做前先说明方案）
1. 键盘 RGB 灯效（WMI sel 2 `sSetRGB` / sel 3 `sSetRGBState`）。
2. 风扇曲线读写（sel 8 `sGetFanCurve` / sel 9 `sSetFanCurve`，32 字节结构，需先逆向，谨慎）。
3. Fn Lock（sel 10）、开机提示音（sel 11）。
4. 菜单栏图标/Dock 图标；把 MHelper 的面板整合进来。
5. 亮度升级"真·原生"：先验证 `IODisplaySetFloatParameter` 在 NootedGreen 下是否可用（当前返回 `-536870201` 不可用，仍用覆盖层）。

### 约束 / 已知限制
- Fn+F4/F5/风扇物理键在 EC/ATKD 层被消费，App 收不到，只能用 ⌃⌥ 组合键替代。
- 本机 WMI 不提供风扇转速/温度读数。
- 改完务必 `bash 构建.sh` 编译通过，并给出验证步骤（点哪里、看什么现象、看 `/tmp/asus_keys.log`）。

### 第一步要做的
1. 确认命令行工具装好、`bash 构建.sh` 能编译通过；
2. 把 `main.swift` 底部过时文案"图形加速：Intel 核显 0xa7a0 无 macOS 驱动"改成"已加速（NootedGreen，VRAM 1536MB / Metal 2）"；
3. 编译安装到 `/Applications/ASUS控制台.app` 并启动验证。
