# 交接提示词（复制到 ASUS软件 工作区的新会话来继续开发）

你是 macOS Swift/SwiftUI 开发者。请在**当前工作区（ASUS软件）**继续开发一个原生 App「ASUS 控制台」，并先阅读同目录下的 `技术数据.md` 与 `ASUS控制台-源码/` 里的代码。

## 背景
这台笔记本是黑苹果：ASUS Zenbook UX3402VA、i9-13900H、32GB、Intel Iris Xe(8086:0xA7A0)、macOS 26.7.3（OpenCore，核显已用 NootedGreen 驱动栈加速）。没有官方 Armoury Crate，所以我用 ASUS WMI（MHelper 的内核驱动 `org.franciumos.mhelper.driver`）自己做了一个 SwiftUI 控制台。

## 目标
维护并增强「ASUS 控制台」App，让日常能方便地调：屏幕亮度/护眼、性能模式(风扇曲线)、键盘背光、充电上限，并显示系统状态。

## 代码位置
- 源码：`ASUS软件/ASUS控制台-源码/`（main.swift、icon.swift、AppIcon.icns、构建.sh）
- 已安装：`/Applications/ASUS控制台.app`（bundle id `com.local.asusconsole`）
- 构建：`bash 构建.sh`（swiftc + 打包 .app + ad-hoc 签名；不要加 `-framework IOKit.ps`）

## 现在已经能用的（不要弄坏）
- 亮度：全屏覆盖层软件调光（暗罩+暖罩），预设 白天/柔和/夜间护眼；⌃⌥↑/↓ 调亮度。
- 性能模式：静音/均衡/性能三键（WMI sSetThermal 0/1/2）；⌃⌥←/→ 切换。
- 键盘背光 0..3（sSetKbd）、充电上限 100/80/60（sSetCharge）。
- 系统状态：CPU/内存/电池/当前模式，2 秒刷新。
- 一键打开 MHelper（风扇曲线/RGB 后端）。

## 请你先做的第一件事
修正 main.swift 底部过时文案："图形加速：Intel 核显 0xa7a0 无 macOS 驱动" → 现在核显已加速（NootedGreen，VRAM1536MB/Metal2），改成正确说明。

## 可选的增强（按价值排序，做之前先说明方案）
1. 键盘 RGB 灯效（WMI sel 2/sSetRGB、sel 3/sSetRGBState）。
2. 风扇曲线读取/写入（sel 8 sGetFanCurve / sel 9 sSetFanCurve，32 字节结构；需先逆向结构定义，谨慎）。
3. Fn Lock 开关（sel 10）、开机提示音开关（sel 11）。
4. 把 MHelper 的 性能/背光/充电 面板整合进来，或加 Dock 图标/菜单栏图标。
5. 亮度想升级成"真·原生亮度"的话，先验证 `IODisplaySetFloatParameter` 在 NootedGreen 下是否可用（目前返回 -536870201 不可用，仍是覆盖层）。

## 约束/已知限制
- Fn+F4/F5/风扇物理键在 EC/ATKD 层被消费，App 收不到，只能用 ⌃⌥ 组合键替代。
- 本机型 WMI 不提供风扇转速/温度读数。
- 改完务必用 `bash 构建.sh` 构建通过，并给出验证步骤（怎么点、看什么现象、看什么日志）。日志在 `/tmp/asus_keys.log`。
