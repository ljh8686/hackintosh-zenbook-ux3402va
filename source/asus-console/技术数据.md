# ASUS 控制台 — 技术数据（交接用）

> 机器：ASUS Zenbook UX3402VA · i9-13900H · 32GB · Intel Iris Xe(8086:0xA7A0) · macOS 26.7.3（黑苹果 OpenCore，已用 NootedGreen 驱动栈实现核显加速）
> App bundle id：`com.local.asusconsole` · 安装位置：`/Applications/ASUS控制台.app`

## 1. 源码与构建
- 源码目录：`~/Documents/deepseek-harness/workspaces/ASUS软件/ASUS控制台-源码/`
  - `main.swift`（约 320 行，全部逻辑）、`icon.swift`（生成图标）、`AppIcon.icns`、`构建.sh`

## 2. ASUS WMI 接口（核心）
- 打开方式（**无需 root**）：
  ```
  IOServiceGetMatchingService(kIOMainPortDefault, IOServiceMatching("AsusWMIControl"))
  IOServiceOpen(svc, mach_task_self_, 0, &conn)   // KERN_SUCCESS
  ```
- kext：`org.franciumos.mhelper.driver`（IOClass=AsusWMIControl，IOUserClientClass=AsusWMIUserClient，匹配 ACPI PNP0C14/ATKD）。
- **外部方法 selector 表（IOExternalMethodDispatch）**：
  | sel | 名称 | 入参 | 出参 |
  |---|---|---|---|
  | 0 | sGetInfo | - | struct 92B |
  | 1 | sSetKbd | scalar 1 | - |
  | 2 | sSetRGB | 6 scalars | - |
  | 3 | sSetRGBState | 5 scalars | - |
  | 4 | sSetThermal | scalar 1 | - |
  | 5 | sSetCharge | scalar 1 | - |
  | 6 | sSetPanelOD | scalar 1 | - |
  | 7 | sSetDGPU | scalar 1 | - |
  | 8 | sGetFanCurve | struct 32B | struct 32B |
  | 9 | sSetFanCurve | struct 32B | - |
  | 10 | sSetFnLock | scalar 1 | - |
  | 11 | sSetBootSound | scalar 1 | - |
- **sGetInfo(sel0) 92 字节布局（实测）**：
  - off0 `version`=2；off4 `features`=0x2099；**off8 `kbdLevel`**；**off12 `thermalPolicy`（0 静音 / 1 均衡 / 2 性能）**；其余多为 0xFFFFFFFF（本机型 WMI 不提供风扇 RPM/温度）。
- **合法取值 / feature 位**：thermal 0..2（bit 0x8）；kbd 0..3（bit 0x1）；charge 20..100（bit 0x80）。setter 均返回 kr=0。
- 代码里已封装：`AsusWMI.open()/info()/setThermal()/setKbd()/setCharge()/setFnLock()`。可扩展：sSetRGB(2/3) 做键盘 RGB、sGetFanCurve/sSetFanCurve(8/9) 做风扇曲线、sSetFnLock(10)、sSetBootSound(11)、sSetPanelOD(6)。
- **实测能力（features=0x2099，2026-11-27 逆向 kext 核对）**：sGetInfo/sSetKbd/sSetThermal/sSetCharge/**sSetFnLock(sel10) 可用**；`sSetRGB(2)`、`sSetRGBState(3)`、`sSetPanelOD(6)`、`sSetDGPU(7)`、`sGetFanCurve(8)`、`sSetFanCurve(9)`、`sSetBootSound(11)` 均返回 `kIOReturnUnsupported(-536870201)`（对应 feature 位未置位）。即本机型 RGB/风扇曲线/开机提示音/dGPU/PanelOD 在驱动层就不支持。
- **sGetInfo 关键偏移**：off8=kbdLevel、off12=thermalPolicy、**off16=chargeLimit（实测 80）**、off68=fnLock（0关/1开，从未设置过为 -1）。

## 3. 屏幕亮度（覆盖层软件调光）
- 背景：本机（IONDRV→NootedGreen）用 gamma `CGSetDisplayTransferByFormula` 返回成功但物理无变化 → 改用**全屏覆盖层窗口**调光。
- 实现 `OverlayDimmer`：两个全屏 borderless 窗口
  - 暗罩：level=300，`black` alpha = `1-level`（level 0.2..1.0）
  - 暖罩：level=301，`NSColor(1,0.55,0.15)` alpha = `warm*0.5*max(0.2,level)`
  - 面板窗口层级：激活时 302、失活时 0（`setPanelLevel`）。
- 预设：白天(level1.0 warm0)/柔和(0.82/0.12)/夜间护眼(0.6/0.65)。关闭窗口/退出会 `reset()`。
- 备注：`AppleBacklightDisplay` 已加载但 `IODisplaySetFloatParameter("brightness")` 返回 -536870201，原生 PWM 亮度拿不到 → 继续用覆盖层。

## 4. 全局热键
- `HotkeyTap`：`CGEvent.tapCreate(.cghidEventTap, .headInsertEventTap, .listenOnly, mask=(1<<14)|(1<<keyDown))`。
- systemDefined(type 14, subtype 8)：`kc = data1 >> 16`，kc==3→加亮，kc==2→减暗。
- keyDown 且 ctrl+opt（⌃⌥）：↑(126)加亮、↓(125)减暗、→(124)风扇+、←(123)风扇−。
- **Fn+F4/F5/风扇键在 EC/ATKD 层被 VoodooPS2Keyboard(BrightnessHack)/ATKD 消费，用户态收不到**，所以用可达到的 ⌃⌥ 组合替代。
- 需要"输入监控"权限（TCC ListenEvent）。日志写到 `/tmp/asus_keys.log`。

## 5. 系统监控（Monitor）
- CPU：`host_statistics(HOST_CPU_LOAD_INFO)` 增量算占用；内存：`vm_statistics64`；电池：`IOPSCopyPowerSourcesInfo`。2 秒刷新。

## 7. 验证方法
- 构建后 `open -a "/Applications/ASUS控制台.app"`。
- 拖动亮度滑条应看到屏幕整体变暗/变暖（可 `screencapture` 截图对比亮度均值）。
- 点性能三键 → `ioreg`/kext 读回 off12 变化；键盘背光滑条 → off8 变化；充电上限 → sSetCharge。
- 热键：设好输入监控后按 ⌃⌥↑/↓ 看亮度变化、⌃⌥←/→ 看性能模式变化。

## 8. 第二轮改版（2026-11-27，UI 重绘 + 稳定性修复）
- **界面全中文 + 视觉重绘**：深色玻璃拟态主题（渐变+动态光斑背景、圆角玻璃卡片、悬停高亮、弹簧动画、环形 CPU/内存/电池仪表、顶部状态胶囊）。菜单栏（编辑/显示/窗口/帮助）已随 Info.plist 的 `CFBundleDevelopmentRegion=zh_CN` + `CFBundleLocalizations=[zh-Hans,en]` 本地化为中文。
- **窗口可缩放**：去掉旧的固定 `.frame(width:460,height:850)`+`.windowResizability(.contentSize)`，改为 `ContentView.frame(minWidth:430,minHeight:520)` + `.windowResizability(.contentMinSize)` + `.defaultSize(520x800)`；`AppDelegate.fitWindow()` 启动时统一设为 520×min(760,可见高-40) 并居中（覆盖旧版保存的过大窗口）。
- **性能模式回退根因**：MHelper.app（LSUIElement 菜单栏程序）把策略存在 `~/Library/Preferences/org.franciumos.mhelper.app.plist`（键 `policy`，0 静音/1 均衡/2 性能），并会周期性重载偏好回写，把 App 设的 2 顶回 1。修复：`MHelperPrefs.sync()` 在每次设置时把 mode/kbd/charge/fnLock 写回 MHelper 偏好；`Monitor.sample()` 每 2 秒读 off12，若与用户选择不一致就重新 `setThermal` 落实（策略守护）。设置同时持久化到 `com.local.asusconsole` 的 UserDefaults（键 mode/kbd/charge/fnLock）。
- **MHelper 按钮无反应根因**：MHelper 是菜单栏程序，`NSWorkspace.open(.app)` 对已运行的 LSUIElement 无任何可见反应。改为「更多工具（MHelper）」卡：说明其在右上角菜单栏，并提供「重启」按钮（terminate + 重新 open，可见菜单栏图标重现）。
- **按键通道补充**：新增 `HIDConsumerTap`（IOHIDManager 匹配 UsagePage 0x0C/Usage 0x01，虚拟设备 "MHelper Fn Keys"），把消费者页 usage 0x6F/0x70 映射到亮度加减，日志 `/tmp/asus_hid.log`。注意：读取 HID 需「输入监控」TCC 权限，本机当前 `IOHIDManagerOpen` 返回 `kIOReturnNotPermitted(-536870174)`，需在 系统设置→隐私与安全性→输入监控 中勾选 ASUS控制台 后才生效。
- **Fn+F4/F5 结论（未变）**：`/tmp/asus_keys.log` 只有音量类 `SYSDEF kc=0/1` 与 ⌃⌥ 组合，从未出现亮度 kc=2/3 或 F4/F5 的 keyDown，确认 F4/F5 在 EC/ATKD 层被消费、MHelper kext 也未把它们转成消费者键送给用户态，App 无法接收；请继续用可达的 ⌃⌥↑/↓（亮度）与 ⌃⌥←/→（性能模式）。

## 11. 合并 MHelper + 菜单栏常驻（2026-11-27）
- **冲突根因**：MHelper.app（`org.franciumos.mhelper.app`，LSUIElement）既是登录项又会周期性从 `~/Library/Preferences/org.franciumos.mhelper.app.plist` 重载 `policy` 并回写，把本 App 设的「性能(2)」顶回「均衡(1)/节能」。
- **取舍**：保留 ASUS 控制台为唯一控制源；MHelper 仅保留 kext（虚拟 HID 设备 "MHelper Fn Keys" 由 kext 提供，不受影响）。已用 `osascript ... delete login item "MHelper"` 移除其开机自启，现登录项只剩 magpie / ASUS控制台；App 启动时 `MHelperGuard` 会在 MHelper 被手动拉起后 2–5 秒内将其 terminate。
- **设置单一真相**：`Monitor.shared` 把 mode/kbd/charge(/fnLock) 持久化到 `com.local.asusconsole`，`applySavedOnLaunch()` 开机只回写「用户确实设过」的键（避免把未设的 fnLock 写成 0）；仍同步写 MHelper 偏好键，避免其残留值作乱。
- **菜单栏常驻**：`MenuBarExtra`（`.menuBarExtraStyle(.window)`，宽 300）提供 性能模式 / 键盘背光 / 充电上限 / 亮度·护眼预设 / 打开控制台 / 退出，全部走同一套 `setMode/setKbd/setCharge`。关闭主窗口只销毁窗口，App 继续驻留菜单栏；再次打开走 `.asusShowMain` → `openWindow(id:"main")` 重建。
- **可关闭/可重开**：`applicationShouldTerminateAfterLastWindowClosed = false`；Dock 点击经 `applicationShouldHandleReopen` 重新弹窗。
- **恢复 MHelper**：`osascript -e 'tell application "System Events" to make login item at end with properties {path:"/Applications/MHelper.app", hidden:false}'`。
- **实测**：构建 exit 0；`/tmp/rdmode` 连续 8×5s 读 off8/12/16/68 恒为 `kbd=3 thermal=2 charge=80 fn=1`（MHelper 不在也不回退）；窗口 520×730，菜单栏面板 AX 位置 (380,82) 尺寸 300×305。
- **小问题**：早期 `com.local.asusconsole` 的 `level` 曾被存成字符串（`"0.6597..."`），导致亮度界面回落到 100%；后续由滑条重写为 Double 即恢复。
