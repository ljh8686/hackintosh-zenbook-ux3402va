## 背景与结论速览
| 硬件 | 结论 | 方案 |
|---|---|---|
| 内置麦克风 Intel SST 数字麦 | ALC294 声卡上**没有**内置麦（Wi-Fi 旁另有 Intel 智音 SST 数字麦，Win 设备 `INTELAUDIO\...VEN_8086&DEV_AE20&SUBSYS_104316A3`），macOS 无 SST 驱动 → 必须装第三方 SST 驱动 | `labrouss/IntelSSTDMIC` 1.0.3 + `-sstdmicforce` |
| 触控板 ASUE120C (I2C-HID) | 固件用 **APIC 中断 59**（>47，VoodooI2C 拒绝）；且 OpenCore **ACPI→Patch 先于 ACPI→Add**，对 Add 里的 DSDT 打的补丁从未生效 | 直接改 DSDT 的 TPD0 `_CRS`：APIC(SBFI)→GPIO(SBFG)，T2 再把 GPIO pin 设为 0xAF |
| 内置扬声器 Cirrus CS35L41 (SPI, 板 1043:16A3) | 硬件可识别(2×CS35L41 走 SPI)，但原厂 kext 因"外接升压"板被元数据门拒、且无 16A3 调音 | 源码移植 CirrusAudioFixup：放开外接boost元数据门 + 加 16A3 固件条目(借同门 ASUS 调音) |

## 1. 麦克风（IntelSSTDMIC）
- 已装 `com.labrouss.IntelSSTDMIC` 1.0.3 到 `EFI/OC/Kexts`，Kernel Add 顺序 `Lilu→AppleALC→SimpleHDA→IntelSSTDMIC`。
- boot-args(266字符)：原 GPU 参数 + `-sstdmiclayout=auto -sstdmicfw=adl -sstdmicforce -sstdmicdbg`。
  - 本机 HDA=`pci8086,51ca` 不在 IntelSSTDMIC 默认 `IOPCIPrimaryMatch`(51c8/51cc/51c9/51cd) 内，故必须 `-sstdmicforce` 强制。
  - 该 kext 用 `PE_boot_args()` 读全量 boot-args（不受 Lilu 228 截断影响）。
- 验证方法：冷启动后「语音备忘录」录 5 秒，读录到的 .m4a 峰值（此前全程 -78dBFS 表示没录到）。
- 回退：`回退-麦克风恢复config.command`。

## 2. 触控板（DSDT 直接改）
- 根因：TPD0 `_CRS` 返回 `ConcatenateResTemplate(I2CM(I2CX,BADR,SPED), SBFI)`，SBFI 是 APIC 中断（IRQ 0x3b=59）。VoodooI2C 只认 GPIO(SBFG) 或 <=47 的 APIC。
- 两个补丁（artifacts）：
  - **T1** `DSDT补丁-T1-中断改GPIO.aml`：把 `_CRS` 里 SBFI→SBFG（4 字节 + 表头校验和修正）。低风险，配合已开的 `-vi2c-force-polling` 大概率可用。
  - **T2** `DSDT补丁-T2-GPIO引脚0xAF.aml`：再把 SBFG 的 GPIO pin 由占位 0x0000 改为 `0xAF`（=GNUM(0x0908000F)=0xA0+0x0F，从 DSDT 的 GPCL[8][8] 推算）。整表 iasl 重编译，风险稍高。
- 部署：`部署-触控板.command` 选 1(T1)/2(T2) → 冷启动。回退：`回退-触控板恢复DSDT.command`。

## 3. 扬声器（CirrusAudioFixup 源码移植）
仓库 `hoaug-tran/CirrusAudioFixup`（本机 xcodebuild 不可用，用 clang++ 手动编译）。两处修改：
1. `Devices/Amplifiers/CS35L41/Board/BoardMetadataFallback.hpp`：把外接boost元数据门放开：
   ```diff
   - if (!facts->internalBoost || facts->count != 2) {
   + if (facts->count != 2) {
   ```
   （其余代码本来就按 `internalBoost` 计算 boost-type/gpio1-func；本机 SSDT 提供 `_DSD` → `mapGPIO=false`，GPIO 接线走 SSDT。）
2. `Devices/Amplifiers/CS35L41/Resources/Generated/FirmwareData.inc`：在 `cs35l41Firmware[]` 末尾加 **2 条 0x1043:0x16A3**（spkid0/spkid1）条目，复用同门 ASUS 调音：
   - 主方案借 **UM3402Y(0x1683)**（同款 Zenbook 14 机身/喇叭，相对更安全）：引用 `cs35l41_dsp1_spk_prot_10431683_{wmfw,spkid1_l0_bin,spkid1_r0_bin}`。
   - 备选借 **ROG Strix G16(0x1C9F)**（立体声两路齐全，机身不同）。
- 已编出两种 kext：`Cirrus扬声器-CirrusAudioFixup-UM3402Y.kext`(默认) / `…-ROG16.kext`。二进制 SHA256：UM=`47419a13…`、ROG16=`78212496…`（完整哈希见 artifacts）。
- ⚠ 风险：调音系数非本机原厂，**极小概率损伤喇叭**——务必低音量试，异常立即 `回退-扬声器.command`。
- 另：此机无 DVD/HDMI 音频外设；耳机(3.5mm)/蓝牙(已修好)/USB 声卡均可零风险出声。
